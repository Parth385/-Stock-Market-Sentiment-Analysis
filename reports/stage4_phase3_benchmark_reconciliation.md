## 2. Baseline Reconciliation: Phase 2 vs. Phase 3

### 2.1 Investigation of Predicted Probabilities

To determine whether the discrepancy between Phase 2 and Phase 3 market-only baselines was caused by data divergence, code drift, or classification thresholds, we extracted the raw out-of-sample test predicted probabilities from both parquet artifacts:
- Phase 2: `prob_logreg_setup_b_opening_bell` in `data/predictions/predictions_market_baselines.parquet`
- Phase 3: `Exp_B1_MktOnly_logreg_prob` in `data/predictions/predictions_sentiment_experiments.parquet`

**Audit Verification Result:**
$$\max_{i \in \text{Test}} \left| \hat{p}_{i, \text{Phase 2}} - \hat{p}_{i, \text{Phase 3}} \right| = \mathbf{0.00000000 \times 10^0}$$

The continuous predicted probabilities generated by Phase 2 and Phase 3 are **100% numerically identical to 16 decimal places**. The exact same identity holds for Random Forest ($|\Delta p| \le 2.22 \times 10^{-16}$, machine epsilon) and XGBoost ($|\Delta p| = 0.0$). 

Because continuous probabilities are identical:
- **ROC-AUC is identical:** $0.544525$ in both Phase 2 and Phase 3.
- **Brier Score is identical:** $0.248019$ in both Phase 2 and Phase 3.

### 2.2 The Root Cause: Threshold Selection Methodology

The difference in hard-label classification metrics (Accuracy, Precision, Recall, F1) stems entirely from the classification decision threshold:

1. **Phase 2 Methodology:** Applied a fixed, default threshold of $\mathbf{\theta = 0.500}$.  
   Because the training set positive prevalence was $46.80\%$ (and test prevalence was $47.63\%$), raw predicted probabilities naturally hovered slightly below $0.50$. Applying $\theta = 0.500$ caused the model to predict the majority negative class on $89.5\%$ of test observations. While this mechanically boosted accuracy to **53.77%**, positive recall was an unviable **12.03%** and Macro F1 was **0.4369**.
2. **Phase 3 Methodology:** Enforced Methodological Requirement 9:  
   *"Document the prediction threshold used for classification. If selecting a threshold using validation data, freeze it before test evaluation."*  
   In Phase 3, `find_best_threshold(y_val, y_prob_val)` optimized the threshold on the 2024 Validation set to maximize Macro F1. The validation grid search selected $\mathbf{\theta^* = 0.475}$. When this validation-frozen threshold was applied out-of-sample to the identical test probabilities, it rebalanced positive recall (**59.74%**) and Macro F1 (**0.5177**), yielding an accuracy of **51.90%**.

## 4. Brier Reference & Probability Quality Analysis

### 4.1 Derivation of Climatology Reference Baseline

In meteorological and statistical probability forecasting, comparing a Brier score solely to $0.2500$ assumes an uninformative $50/50$ prior. However, when classes are imbalanced, an uninformative forecaster who knows only historical class frequency predicts a constant probability equal to the training set positive prevalence $p_{\text{train}}$:

1. **Training Set Empirical Prevalence (2020–2023, $N = 14,835$):**
   $$p_{\text{train}} = \frac{6,943}{14,835} = \mathbf{0.468015} \quad (46.80\%)$$
2. **Validation Set Empirical Prevalence (2024, $N = 3,690$):**
   $$p_{\text{val}} = \frac{1,742}{3,690} = \mathbf{0.472087} \quad (47.21\%)$$
3. **Out-of-Sample Test Prevalence (2025–2026, $N = 4,590$):**
   $$p_{\text{test}} = \frac{2,186}{4,590} = \mathbf{0.476253} \quad (47.63\%)$$
4. **Theoretical 50/50 Brier Reference ($BS_{50/50}$):**
   $$BS_{50/50} = \frac{1}{N_{\text{test}}} \sum_{i=1}^{N_{\text{test}}} (y_i - 0.50)^2 = \mathbf{0.250000}$$
5. **Climatology Brier Reference ($BS_{\text{clim}}$):**
   Predicting the constant training base-rate $p_{\text{train}} = 0.468015$ across all test days yields:
   $$BS_{\text{clim}} = p_{\text{test}}(1 - p_{\text{train}})^2 + (1 - p_{\text{test}})(0 - p_{\text{train}})^2 = \mathbf{0.249504}$$

## 5. Critical Review of Empirical Claims & Statistical Significance

### 5.1 Disentangling the Metrics: Accuracy vs. Discrimination vs. Calibration

A central requirement of rigorous financial machine learning is avoiding conflation between classification accuracy, ranking discrimination, and calibration:

1. **The Exp B4 (FinBERT Logistic Regression) Paradox:**  
   - Test Accuracy **increased** from $51.90\%$ to **$53.53\%$** ($+1.63\%$ absolute, $+3.15\%$ relative).
   - Test ROC-AUC **decreased** from $0.5445$ to **$0.5377$** ($-0.0068$).
   - Test Brier Score **worsened slightly** from $0.2480$ to **$0.2484$** ($+0.0004$).
   
   **Methodological Explanation:**  
   It is methodologically **incorrect** to claim that FinBERT "improves overall predictive discrimination" in this configuration. ROC-AUC is a threshold-independent measure of the model's global ability to rank positive instances above negative instances. A drop in ROC-AUC proves that global rank discrimination slightly degraded.  
   The gain in accuracy occurred because FinBERT features shifted marginal probabilities near the decision boundary ($\theta^* = 0.475$) into better alignment with the empirical test distribution, lifting both Specificity ($44.76\% \to 55.03\%$) and Macro F1 ($0.5177 \to 0.5345$).
2. **Where Discrimination DID Improve:**  
   Genuine discrimination gains occurred in tree models under Loughran-McDonald sentiment:
   - Setup A XGBoost: ROC-AUC increased from $0.4882$ to **$0.5103$** ($+0.0221$ / $+4.52\%$).
   - Setup B XGBoost: ROC-AUC increased from $0.5211$ to **$0.5320$** ($+0.0109$ / $+2.09\%$).
   - Setup B Random Forest: ROC-AUC increased from $0.5279$ to **$0.5353$** ($+0.0074$ / $+1.40\%$).

### 5.2 Formal Statistical Significance Testing

To verify whether the $+1.63\%$ accuracy gain in Exp B4 Logistic Regression and the $+3.42\%$ accuracy gain in Exp A4 XGBoost are statistically distinguishable from random chance, we conducted formal hypothesis tests:

#### Test 1: Unadjusted McNemar's Test (Assuming i.i.d. observations)
Evaluating discordant pairs on the $2 \times 2$ test contingency table ($N = 4,590$):
- **Setup B Logistic Regression (Exp B1 MktOnly vs. Exp B4 FinBERT):**
  - Both Correct: 1,714 | Both Wrong: 1,465
  - B1 Correct & B4 Wrong: $b = 668$
  - B4 Correct & B1 Wrong: $c = 743$ (Net gain = $+75$)
  - McNemar's $\chi^2$ (with continuity correction): $\mathbf{3.8809}$
  - Asymptotic p-value: $\mathbf{p = 0.0488}$ *(Marginally significant under i.i.d. assumption)*
- **Setup A XGBoost (Exp A1 MktOnly vs. Exp A4 FinBERT):**
  - Both Correct: 1,065 | Both Wrong: 1,040
  - A1 Correct & A4 Wrong: $b = 1,164$
  - A4 Correct & A1 Wrong: $c = 1,321$ (Net gain = $+157$)
  - McNemar's $\chi^2$ (with continuity correction): $\mathbf{9.7932}$
  - Asymptotic p-value: $\mathbf{p = 0.00175}$ *(Significant under i.i.d. assumption)*

#### Test 2: Session-Clustered Block Permutation Test (Correcting for Non-i.i.d. Panel Structure)
The unadjusted McNemar test fundamentally assumes that all 4,590 test observations are independent. In stock market panel data, this assumption is **severely violated**:
- All 15 stocks share the exact same 306 test trading sessions.
- On macroeconomic or geopolitical event days (e.g., Union Budget announcements, US CPI releases, RBI policy shifts), market-wide systematic shocks cause model prediction errors to be **heavily correlated across stocks within the same trading session**.
- Treating 4,590 observations as independent artificially inflates degrees of freedom and deflates p-values.

To correct for contemporaneous cross-stock correlation, we implemented a **Session-Clustered Block Permutation Test** ($2,000$ cluster permutations, randomly swapping prediction vectors across all 15 stocks simultaneously at the trading session level):

$$\text{Observed Accuracy Gain: } \mathbf{+1.63\%}$$
$$\text{Session-Clustered Two-Tailed p-value: } \mathbf{p = 0.0820}$$

**Statistical Verdict:**  
When correctly adjusting for cross-sectional market correlation across trading sessions, the $+1.63\%$ accuracy gain of FinBERT Logistic Regression in Setup B has a p-value of **$0.0820$**. It is **not statistically significant at the conventional $\alpha = 0.05$ level**, though it is significant at the $\alpha = 0.10$ level.

## 6. Synthesis & Final Audit Conclusions

1. **Baselines are 100% Reconciled:** The difference between Phase 2 ($53.77\%$) and Phase 3 ($51.90\%$) baseline accuracy is entirely an artifact of moving from an uncalibrated default threshold ($\theta = 0.500$) to an honest validation-frozen threshold ($\theta^* = 0.475$). Predicted probabilities and ROC-AUC ($0.5445$) are identical.
2. **Clear Feature & Run Accounting:** 12 configurations across 2 setups and 3 algorithms produced exactly 36 newly trained models in Phase 3, supplementing the 6 original models from Phase 2 (42 models total).
3. **Probability Quality vs. Directional Classification:** Sentiment models do not produce superior probability calibration over climatology ($BS_{\text{clim}} = 0.2495$), but they do provide valuable directional regularization that improves positive-class recall and macro F1.
4. **Statistical Restraint:** The aggregate lift of sentiment ($+1.63\%$) must be characterized as a modest, suggestive improvement ($p = 0.0820$ clustered) rather than an overwhelming market anomaly, with the true value of sentiment concentrated in high-liquidity, high-news bellwethers (SBIN, ICICIBANK, RELIANCE).
